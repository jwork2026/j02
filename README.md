# 葫芦娃排序作业

这是一个用 Java 编写的面向对象建模示例。

运行 `make` 可以编译并运行当前示例：

```shell
make
```

当前实现可以把一维队伍按排行排好。

运行 `make visual` 可以启动一个只使用 Java 标准库 Swing 编写的轻量级可视化引擎。可视化程序将排序计划展开为场景时间线，支持播放、暂停、单步和重置；它只读取快照，不修改排序模型。

## 作业要求

1. 仔细阅读代码，理解其面向对象模型，指出其中不合理的设计之处并改正。

2. 消除一维交换中的“瞬移”：当前 `Huluwa.exchangePositionWith` 直接互换两个葫芦娃的位置值，两人可以瞬间出现在对方的位置。请修改设计，只允许相邻葫芦娃交换位置来实现葫芦娃的移动。

3. 将排序问题扩展到二维空间：实现 `n` 个葫芦娃在 `m * m` 矩阵中的排序，其中 `n = m^2`。同样，葫芦娃只能与（上下左右四个方向）相邻的葫芦娃交换位置来移动，并要求排序过程的位置交换次数最少。

## 提交方式

- 第 2、3 题的代码保存在 `src` 目录下，可以覆盖原有代码。
- 将第 1 题的分析，以及第 2、3 题自己的面向对象设计思路，写入 `REPORT.md`。
- AI 会针对 `src` 下的代码和 `REPORT.md` 进行自动评审。
